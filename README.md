# Capybara Clicking Game

A cozy browser clicker game with a capybara, coin upgrades, and unlockable decorations.

## Play

Open `index.html` in a modern browser. No build step or dependencies are needed. Google Fonts is optional; the interface uses fallback fonts offline.

Click the capybara to earn coins. Spend wallet coins in the upgrade shop to increase coins per click. Lifetime earnings advance levels without decreasing when coins are spent. Each level-up unlocks a random wardrobe item; wear one decoration at a time.

Progress, upgrades, and outfits are saved in browser local storage. Reset game clears this progress and returns to the starting state. Sound can be toggled in the header.

## Files

- `index.html`: interface and layout
- `style.css`: responsive styling and animations
- `game.js`: game logic, audio, and saves
- `assets/capybara-cozy.png`: current capybara image
- Other image assets: original and reference artwork
